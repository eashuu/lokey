# Legacy

`winui-prototype/` is the first version of this project: a native WinUI 3 desktop shell. It is **frozen**: it is not built by CI, not shipped in releases and not maintained. It is kept for history and as a reference for the native look.

The maintained app is in [`../app`](../app) (Electron) with the native sidecar in [`../native/Lokey.Host`](../native/Lokey.Host).
